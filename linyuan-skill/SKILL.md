## 核心公式

> 好企业 = 行业 ＋ 垄断 ＋ 成瘾

- **行业**：朝阳行业，未来受众市场越来越大（"行业不同，未来就不同"）。
- **垄断**：掌握定价权、产品排他，任何风险都来自竞争，垄断把风险化为零（"投资没有别的诀窍，就是垄断"）。
- **成瘾**：让人反复消费的产品（白酒、咖啡、烟草、依赖药物），利润源源不断。

## 分析工作流

分析任何公司/股票时按以下顺序执行，每步都要落到具体证据（行业数据、财报数字、产品事实），不凭印象下结论：

### 第 1 步 · 行业判定
- 是否朝阳行业？市场规模是否足够大且长期扩张？
- 林园只投两条主线：① 与嘴巴消费相关的垄断消费品（白酒为代表）；② 与三大慢性病（糖尿病、心脏病/心脑血管、高血压）相关的医药医疗。
- 行业景气度与进场节奏：只在上升期投资，不在衰落期踏入。

### 第 2 步 · 垄断判定
用"垄断七大特征"核对（详见 references）：自然垄断（独占资源）/经济垄断（规模优势）/行政垄断（特许经营权）；老字号（品牌心智+独门定价权）；行业龙头（市场证明过的强势企业）。
- 有老大就不选老二；分不出老大老二时组合配置两家。
- 产品是否从不降价、先款后货、供不应求？

### 第 3 步 · 成瘾判定
- 是否属于瘾品：反复消费、欲罢不能、离不开（白酒、慢性病用药是最典型的"刚需+成瘾"）。
- 消费频次与不可替代性决定利润的可持续性。

### 第 4 步 · 财务验证（六大指标）
| 指标 | 林园标准 |
|---|---|
| 利润总额 | ≥1 亿元（"还不如个体户赚得多"的公司不投） |
| 每股净资产 | 不去关心（能赚钱的净资产才有效） |
| 净资产收益率 | 标准 >20%（10% 以下免谈） |
| 产品毛利率 | 标准 >20%，且高、稳定、趋升（下降的公司看都不看） |
| 应收账款 | 注意回避（无法判断能否收回） |
| 预收账款 | 越多越好（先收款后发货＝已获订单） |

### 第 5 步 · 量化核对
- 市盈率倍数 ≈ 未来 3 年复合增长的最低百分比（市盈率 20 倍须对应增长 20%+）。
- 未来 3 年复合增长率底线 18%。
- 毛利率 >20% 且稳定；现金流越多越好。
- 跟踪企业及主要竞争对手至少 3 年再大量买入；只要存在 5% 的不确定性就不买入。
- 算清最坏结果下未来 3 年的账——算得清才敢满仓。

### 第 6 步 · 输出结论
按下列结构输出（用户无特殊要求时采用）：

1. **一句话结论**：是否符合"行业＋垄断＋成瘾"框架，确定性高/中/低。
2. **行业面**：归属主线、景气判断。
3. **垄断面**：命中哪类垄断、护城河来源。
4. **成瘾/需求面**：消费属性与可持续性。
5. **财务面**：六大指标逐项对照 + 量化标准核对（用真实财报数字）。
6. **风险与证伪**：什么情况下该逻辑被破坏（毛利率下降、垄断被打破、行业见顶、财务造假信号）。
7. **出处**：涉及林园原话或书中案例时标注出自哪本书。

## 常用判断速查

- **不熟不做**：只在能力圈内投资，不熟悉的行业坚决不碰。
- **三类确定性企业**：垄断行业企业 > 老字号企业 > 龙头企业（特许经营权收益最稳定）。
- **医药逻辑链**：老龄化确定 → 病患增多确定 → 用药成瘾确定 → 利润增长确定 → 股价上升确定（"未来 30 年最差结果赚 100 倍"）。
- **无风险套利**：可转债（涨时猛如股、跌时稳如债）、认沽权证保底价、打新、国债逆回购——财富超一半来自无风险套利。
- **牛熊策略**：熊市末期满仓建仓（"套住的都是金项链"）→ 牛市初期满仓捂股（"在痛苦中赚钱"）→ 牛市中期聚焦小盘绩优 → 牛市末期兑现离场（"贵出如粪土"）。
- **买入前提**：盈利确定 + 股价有上升空间（低位进场留安全边际）二者缺一不可。

## 数据与口径纪律

- 三本书中的资产数值（如 300 亿、千亿在管规模）为媒体报道口径，输出时标注"未独立核实"。
- 案例数字（茅台毛利率 83%、汾酒毛利率 59.7%→72.1%、片仔癀 14 次提价累计 4 倍、招行转债 102.5 元、五粮液权证 7.96 元底、上海机场 13.6 元底等）出自书中原文，代表出版时点口径，不适用当前行情。
- 本框架是分析视角而非投资建议；需要实时行情/最新财报时用行情工具获取现价与当期数据，不与书中旧口径混淆。
